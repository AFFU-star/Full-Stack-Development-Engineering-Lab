# React Fundamentals Learning Resources

## Why These Resources?

React is not just a JavaScript library; it is a component-driven approach to building modern user interfaces. The resources below have been carefully selected to help students understand React from both an academic and industry perspective.

---

# Official Documentation

## React Official Documentation

Link:
https://react.dev

Why Read?

The official documentation maintained by the React team. It provides the most accurate and up-to-date explanation of React concepts.

Recommended Topics:

* Quick Start
* Describing the UI
* Adding Interactivity
* Passing Props
* Conditional Rendering
* Rendering Lists

Industry Value:

Every professional React developer regularly references the official documentation.

# Modern JavaScript Prerequisites

## JavaScript.info

Link:
https://javascript.info

Why Read?

React heavily relies on modern JavaScript concepts such as Arrow Functions, Destructuring, Template Literals, and Array Methods.

Recommended Topics:

* Functions
* Objects
* Arrays
* Destructuring
* Arrow Functions
* Promises

Industry Value:

Strengthens JavaScript foundations required for React development.

# Interactive Learning Tools

## Babel REPL

Link:
https://babeljs.io/repl

Why Use?

Allows students to observe how JSX is transformed into standard JavaScript.

Experiment:

Paste a React component and inspect the generated JavaScript output.

Learning Outcome:

Understand what happens behind the scenes when React code is compiled.

---

## CodeSandbox

Link:
https://codesandbox.io

Why Use?

Cloud-based React development environment for rapid experimentation.

Experiment:

Create and modify React components directly in the browser.

Learning Outcome:

Develop and test React applications without local setup.

---

# React Architecture References

## Thinking in React

Link:
https://react.dev/learn/thinking-in-react

Why Read?

Explains how large user interfaces can be broken into reusable components.

Learning Outcome:

Understand component hierarchy, data flow, and UI decomposition.

Industry Value:

One of the most important skills for frontend system design.
