# Proof-of-Work Assignment: Product Showcase Dashboard

## Assignment Overview

Modern web applications are built using reusable user interface components. Rather than creating every page from scratch, software engineers design modular components that can be reused throughout an application.

This assignment introduces students to React's component-based architecture by building a Product Showcase Dashboard.

The objective is to understand how modern frontend applications are structured and how React enables scalable UI development through reusable components.

---

## Problem Statement

Develop a Product Showcase Dashboard using React Functional Components.

The application should display multiple products using reusable Product Card components.

Each product should contain:

* Product Name
* Category
* Price
* Rating
* Product Image
* Availability Status

---

## Learning Objectives

Upon successful completion, students should be able to:

* Understand JSX syntax
* Create Functional Components
* Pass and consume Props
* Build reusable UI elements
* Organize components effectively
* Understand component composition

---

## Functional Requirements

### Task 1: Create Product Card Component

Design a reusable Product Card component capable of displaying product information.

---

### Task 2: Display Multiple Products

Create a product dataset and render multiple Product Cards.

---

### Task 3: Use Props

Pass product information dynamically through props.

---

### Task 4: Organize Components

Separate the application into meaningful components such as:

* App
* Header
* ProductCard
* ProductList
* Footer

---

### Task 5: Responsive Layout

Arrange product cards using modern CSS layouts.
