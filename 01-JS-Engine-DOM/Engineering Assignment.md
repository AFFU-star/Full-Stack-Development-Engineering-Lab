# Proof-of-Work Assignment 01: Student Grade Analyzer

## Assignment Overview

In educational institutions, student performance is often evaluated using marks, percentages, and grade classifications. As a JavaScript developer, your task is to design and implement a browser-based application that automates this process.

This assignment is designed to help you apply JavaScript fundamentals in a realistic problem-solving scenario while strengthening your understanding of variables, functions, arrays, conditional logic, DOM manipulation, and event handling.

---

## Problem Statement

Develop a Student Grade Analyzer application that accepts marks for multiple subjects and automatically computes:

* Total Marks
* Percentage
* Grade Classification

The application should display the results dynamically within the browser interface.

---

## Learning Outcomes

Upon successful completion, students should be able to:

* Use variables to store data
* Perform arithmetic operations
* Implement functions
* Work with arrays
* Manipulate DOM elements
* Handle user events
* Validate user inputs

---

## Suggested Development Approach

Step 1:
Design a simple user interface using HTML.

Step 2:
Collect subject marks through form inputs.

Step 3:
Validate all inputs before processing.

Step 4:
Calculate total and percentage.

Step 5:
Assign grades using conditional statements.

Step 6:
Display results dynamically using JavaScript DOM methods.
